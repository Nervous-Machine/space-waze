# Atlas of Useful Space

The public site for the Atlas of Useful Space — a map of where certainty about
the space environment is earned from measurement, where models stand in
(stamped and staked), and where no measurements exist yet, with the specific
measurement that closes each hole.

Built with the [Nervous Machine](https://nervousmachine.com) framework.

Everything served lives in `public/`. The learning runs, pipelines, and
framework code live in separate repositories.
